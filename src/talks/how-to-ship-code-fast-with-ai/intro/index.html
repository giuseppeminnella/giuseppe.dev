Protect long-term delivery speed

To be clear: none of this is an argument against using it.

short-term generation speed

Use it, then throw it away.

  • a spike, to see if the idea holds
  • a throwaway script
  • a one-off migration
  • learning an unfamiliar API
  • the first draft nobody will read

Go as fast as you like.

long-term delivery speed

It stays for years.

  • read by people who were not there
  • owned by a team that rotates
  • woken up for at three in the morning
  • audited, and migrated twice
