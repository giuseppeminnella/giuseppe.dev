Solutions · contain the drift: practice, tooling, people

So how do you ship fast without paying for it later? You don’t stop the drift. You contain it.

Practice first. A bounded context contains meaning; an anti-corruption layer contains imported complexity.

Make acceptance expensive: everything that wants in answers these questions first.

Tooling. If a script can say no, don’t ask a model. Deterministic checks first, the LLM last.

The model’s best job is writing new checkers: every finding it keeps repeating becomes a rule a script enforces.

Guardrails drift too. Evals as quality gates check, release after release, that your rules still hold.

Slop at home is fine. The square is sacred. No new shared tool unless it is provably necessary.

As long as a human is legally responsible, the change has to fit in a human head.

Not a giant spec up front: a curated brain close to the code. The spec as memory, not as blueprint.
